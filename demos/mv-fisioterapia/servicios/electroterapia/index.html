Electroterapia en Granada: TENS y electroestimulación

TENS para calmar el dolor y electroestimulación para despertar un músculo que se ha quedado vago después de una lesión o una operación. Se usa como apoyo del tratamiento.

Para qué se usa

  • TENS para aliviar el dolor
  • Electroestimulación para activar un músculo debilitado, como el cuádriceps después de operar la rodilla
  • Apoyo en las fases de más dolor

Cómo es

Se usa como complemento de la terapia manual y del ejercicio, no como tratamiento único.

Preguntas frecuentes

¿Quién no debe usar electroterapia?

No se aplica a personas con marcapasos u otros dispositivos implantados, ni sobre el abdomen o la zona lumbar durante el embarazo, sobre piel dañada o sobre zonas con un cáncer activo, entre otros casos. Se repasa en la valoración.
