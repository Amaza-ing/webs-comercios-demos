# Prototipos de comercios

Propuestas independientes, no oficiales, de diseño web para negocios de Málaga y Granada. Este repositorio contiene exclusivamente las páginas compiladas. AMazaing Pages · MaieuticApps. Los prototipos utilizan fotografías y logos de las webs originales; no representan una relación comercial ni aprobación por parte de los negocios.
